# Umasearch

Проєкт, з лабораторними роботами з дисципліни "Компоненти програмної інженерії. Частина 2. Моделювання та аналіз вимог до програмного забезпечення", КПІ ім. Ігоря Сікорського, 2026.

---

## Про проєкт

Umasearch - це проєкт для гри Umamusume: Pretty Derby, де ви можете шукати гравців які виставили в рентал умок з потрібними вам факторами або сапорт картками. Також сайт дозволяє вам виставляти свій ігровий профіль, щоб інші гравці могли скористатися вашими умами або картками.

---

## Причина вибору теми

У грі відсутня зручна система пошуку гравців у яких можна позичити умок та сапорт картки для кар'єри, які є обов'язковими у грі, через що гравці використовують різні сторонні джерела для пошуку потрібних їм гравців. Цей проєкт буде спрощувати пошук усім гравцям які намагаються досягти кращих результатів у грі.
