## 1. Повний текст промпту

До промпту додано файли: `spec.md` (ER-модель), `spec.md` (актори й цілі), `spec.md` (sequence UC-10), `spec.md` (машина станів UC-10), `erDiagram.mmd`, `traceability-matrix.md`, `user-stories.md`, `readme.md`.

```text
Використовуючи ER-модель, матрицю трасування, user-stories, ears-вимоги, рідмі, 4 специфікації з попередніх лабораторних робіт допоможи мені написати файл spec.md для 5-ї лабораторної роботи. Приблизний розмір файлу 1 сторінка.

Опиши текстово такі розділи:
1. Модулі та шари системи:
- UI (клієнтська частина)
- API / Backend (серверні маршрути, ендпоінти та контролери)
- Сервіси (бізнес-логіка, що покриває методи та сценарії з Sequence та Activity діаграм)
- Data Access (репозиторії, рівень доступу до даних)
- База даних (схема зберігання, прив'язана до сутностей із нашої ER-моделі)
- Зовнішні інтеграції (Payment, SMS/Email, OAuth, External API - усі сторонні сервіси, які фігурували у попередніх діаграмах та сценаріях).
2. Чітка межа системи (System Boundary).
3. Provided та Required інтерфейси.
4. Залежності між компонентами.
```
