# ADR-0003: Rank як довідникова сутність

**Status**: Accepted

**Date**: 2026-10-05

---

## Context

`SharedUma.rank` має формат «літера-ранг + число» (наприклад, "UE3", "UG5"), а повний список значень зберігається як довідник, а не вільний текст (вхідні дані). Admin керує довідниками, зокрема допустимими значеннями rank (`spec.md`, розділ 4). Умки фільтруються за rank (AC-10). Модель має бути в 3NF (AC-03).

## Decision Drivers

- Значення rank обмежені списком, яким керує Admin
- Атомарність атрибутів (AC-03)
- Узгодженість із іншими довідниками (Umamusume, SupportCard, Factor)
- Простий фільтр за rank (AC-10)

## Considered Options

1. Сутність `Rank(id, code UK)` і `SharedUma.rank_id` FK
2. Рядок `SharedUma.rank` з перерахованими в spec допустимими значеннями
3. Два поля: `rank_letter` і `rank_number` у SharedUma

## Decision Outcome

Chosen option: **Option 1**, тому що довідником керує Admin (список може змінюватися без зміни моделі), значення "UE3" є атомарним кодом, а не складеним значенням, і ця схема збігається з іншими довідниками. Фільтр за rank виконується за FK.

## Consequences

### Positive

- Список допустимих значень змінюється даними, а не моделлю.
- Усі довідники в моделі однорідні.
- Немає розбору рядка на літеру й число.

### Negative and risks

- З'являється ще одна сутність і ще одна дія Admin.
- Якщо правила гри змусять фільтрувати за літерою окремо від числа, потрібно переглянути рішення.

### Follow-up actions

- [ ] Додати Rank у `spec.md` (розділи 2, 3, 4) і `erDiagram.mmd`
- [ ] Узгодити з автором повний список кодів rank (джерело: гра)

## Pros and Cons of the Options

### Option 1: сутність Rank

- Pros: Admin керує списком; атомарний код; однорідність довідників.
- Cons: додаткова сутність.

### Option 2: рядок із переліком у spec

- Pros: без нової сутності.
- Cons: список значень зашитий у специфікацію, а за вхідними даними ним керує Admin.

### Option 3: два поля

- Pros: можна фільтрувати за літерою окремо.
- Cons: у вхідних даних rank — одне значення; два поля вигадують структуру; значення більше не береться з єдиного довідника.
