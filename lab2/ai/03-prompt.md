# Промпт №3: user stories, Gherkin-сценарії, матриця трасування та Use Case Diagram

**Модель:** Claude Sonnet 5.5 (Anthropic)

---

## 1. Повний текст промпту

```
Ти допомагаєш виконати лабораторну для проєкту Umasearch. Надаю тобі специфікацію проєкту, специфікацію акторів, додаткові специфікації, ER-модель, ADR-файли, ears вимоги. Нічого не вигадуй і не змінюй.

Ти повинен створити в окремих файлах user stories і Gherkin-сценарії (Given/When/Then). Також ти повинен окремо створити матрицю трасування «вимога-id ↔ сценарій/UC» як таблиця в Markdown. Рендер — Use Case Diagram (PlantUML / Mermaid) з ≥2 типами акторів, include/extend, узагальненням
```

## 2. Що видав ШІ

ШІ видав чотири артефакти (5 файлів):

| Файл | Зміст |
| --- | --- |
| `user-stories.md` | 8 user stories (US-01…US-08) з критеріями, посиланнями на вимоги, AC та UC |
| `umasearch.feature` | 52 сценарії (SC-001…SC-052), 9 блоків Rule |
| `traceability-matrix.md` | таблиця «вимога → UC → сценарії → US» (33 вимоги, усі мають сценарій), а також таблиці include (4 групи) та extend (3 відношення) |
| `use-case-diagram.puml` / `.svg` | діаграма з 3 акторами, 20 use case, 14 include, 3 extend, 2 узагальнення (UC-03 і UC-04 → абстрактний UC-20) |

## 3. Розбіжності між промптом та тим, що видав ШІ

| №   | Вимога промпту | Що зроблено | Розбіжність |
| --- | --- | --- | --- |
